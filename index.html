      ‘번호’를 적어두면 손님이 “1번 2개”처럼 써도 알아듣습니다. ‘다른 이름’에는 손님들이 부르는 이름을 쉼표로 적으세요. 부사·홍로(사과), 샤인(샤인머스캣), 감귤(귤) 같은 흔한 이름은 따로 적지 않아도 알아듣습니다.

      주문 게시글로 목록 만들기

      밴드에 올린 주문 안내 글을 붙여넣으면 번호·상품명·가격을 읽어 목록을 만듭니다.

        이렇게 쓰세요

        1. 상품 목록 탭에서 이번에 파는 상품을 확인합니다. 주문 안내 글을 붙여넣으면 자동으로 만들어집니다.
        2. 밴드 게시글의 댓글을 복사해서 집계 탭 왼쪽 칸에 붙여넣습니다.
        3. 오른쪽에 상품별 합계와 손님별 주문이 바로 나옵니다. 확인이 필요한 댓글만 눈으로 확인하세요.
        4. 합계 복사로 카톡·밴드에 붙여넣거나, 엑셀·시트용 복사로 구글 시트에 붙여넣습니다.

        밴드에서 바로 불러오기 (복사 없이)

        인터넷 주소(https://…)로 올려둔 집계표에서는 밴드 공식 Open API로 댓글을 바로 불러옵니다. 처음 한 번만 토큰을 넣으면 됩니다.

        1. 컴퓨터에서 developers.band.us에 밴드 계정으로 로그인 → My Apps → 서비스 등록 (이름만 적으면 됩니다).
        2. 등록한 서비스에서 Connect BAND account(밴드 계정 연결)을 누르면 Access Token이 나옵니다. 이 토큰을 복사합니다.
        3. 휴대폰으로 집계표 주소를 열고 ‘밴드에서 바로 불러오기’ 칸에 토큰을 넣고 연결하기.
        4. 밴드와 주문 게시글을 고르고 댓글 불러오기. 다시 확인할 때는 같은 버튼을 다시 누르거나 ‘1분마다 새로고침’을 켜두세요.

        토큰은 비밀번호처럼 다루세요. 이 집계표는 토큰을 그 기기에만 저장하고 밴드 외에는 아무 데도 보내지 않습니다.

        댓글 복사하는 법

        • 컴퓨터: 인터넷 창에서 band.us에 로그인 → 주문 게시글 열기 → 댓글을 모두 펼친 뒤 첫 댓글부터 마지막 댓글까지 마우스로 끌어 선택 → Ctrl+C → 이 칸에 Ctrl+V.
        • 휴대폰: 댓글을 길게 눌러 ‘복사’한 뒤 붙여넣고, 다음 댓글도 이어서 붙여넣으면 됩니다. 이름이 같이 복사되지 않으면 댓글 위 줄에 이름을 적어주세요.
        • 이 페이지는 밴드에 직접 접속하지 않습니다. 사장님이 복사한 글만 읽으니 밴드 정책에 막히지 않습니다.

        손님께 이렇게 안내하면 더 정확해요

        주문 글 맨 아래에 붙여두세요.

        📌 주문은 댓글로 “이름 / 상품 수량”으로 남겨주세요. 예) 홍길동 / 사과 2박스, 배 1박스 번호로 주문하셔도 됩니다. 예) 1번 2개, 3번 1개 취소·변경도 댓글로 남겨주세요. 예) 사과 1박스 취소

        이런 표현을 알아듣습니다

        수량사과 2, 사과2개, 사과 x2, 두 박스, 하나요, 2박스 사과
        번호 주문1번 2개, ②번 1개 (상품 목록에 번호가 있을 때)
        규격사과 5키로 2박스 → ‘사과 5kg’ 따로 합계. 같은 과일이 여러 규격이면 무게를 보고 맞는 상품을 고릅니다.
        취소·변경“사과 1박스 취소” → 앞 주문에서 1 빼기, “배 3개로 변경” → 3으로 바꾸기, “주문 취소” → 그 손님 전체 취소
        문의“사과 있나요?”처럼 수량 없는 질문은 세지 않고 따로 보여줍니다.
        무시전화번호, 가격(35,000원), 시간(오후 3시), 동·호수, 배송·택배 같은 말
        다른 형식“이름: 주문” 한 줄 형식, 카카오톡 대화 내보내기 형식도 됩니다.
